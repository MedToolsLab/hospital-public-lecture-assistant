# 公開講座運営アシスタント Ver.1.2

病院・医療機関向けに、公開講座の運営で使う文章と Google Apps Script を生成する静的Webツールです。

講座情報を入力すると、以下をブラウザ内だけで生成できます。

- 自動返信メール用 Apps Script
- リマインダーメール用 Apps Script
- 自動返信メール本文プレビュー
- リマインダーメール本文プレビュー
- Googleフォームタイトル
- Googleフォーム申込案内文
- Googleフォーム送信完了画面文

外部ライブラリ、外部API、サーバー通信は使っていません。入力内容は利用中のブラウザ内で処理され、外部へ送信されません。

公開コード内の病院名、会場名、講師名、住所、電話番号、URLはすべて架空のサンプルです。実運用情報を GitHub リポジトリへ保存しないでください。

## Ver.1.2 の主な機能

- 基本設定の折りたたみ、保存、初期値復元
- 講師マスターの追加、削除、初期化
- 会場テンプレートの追加、削除、初期化、自動入力
- 診療科・職種に応じた講師候補表示
- 候補外の講師名の自由入力
- 講師名の職種・役職前スペース補正
- 開催日から曜日を自動入力
- 開催時間候補と「その他」時間の自由入力
- ホームページ用テーマ入力
- 1講座分のホームページ掲載文生成
- 各出力のコピー機能

## 使い方

1. `index.html` をブラウザで開きます。
2. 「基本設定を開く」を押し、病院名、部署名、電話番号、URL、住所、送信者名を入力します。
3. 「基本設定を保存」を押すと、このブラウザ内に保存されます。
4. 「講師マスター管理」で診療科・職種と講師名を登録します。
5. 「会場テンプレート管理」でよく使う会場を登録します。
6. 必要に応じて会場テンプレートを選び、講座情報へ自動入力します。
7. 講座情報を入力し、「コードを生成」を押します。
8. 表示された各ボックスの「コピー」ボタンから、必要な文章やコードをコピーします。

「サンプルを入力」を押すと、架空の動作確認用データが入ります。保存済みの基本設定、講師マスター、会場テンプレートは上書きしません。

## localStorage に保存する情報

このツールは、実運用情報をブラウザの `localStorage` に保存します。

- `publicLectureAssistant.basicSettings.v1`：基本設定
- `publicLectureSpeakerMaster`：講師マスター
- `publicLectureVenueTemplates`：会場テンプレート

登録した内容は外部へ送信されません。ただし、ブラウザや端末を変更すると共有されません。ブラウザデータを削除すると、保存した設定、講師マスター、会場テンプレートも消えます。

## 基本設定

初回アクセス時は架空のサンプル値が表示されます。実運用では、各施設の情報へ変更してから「基本設定を保存」を押してください。

「基本設定を初期値に戻す」を押すと、保存済みの基本設定を削除し、架空のサンプル値へ戻します。

## 講師マスター管理

公開コード内の講師名は架空のサンプルです。実在する職員名は、画面から登録し、ブラウザ内の `localStorage` にのみ保存してください。

### 講師の追加

1. 「講師マスター管理」で診療科・職種を入力します。
2. 講師名を入力します。
3. 「講師を追加」を押します。

### 講師の削除

1. 登録済み講師の一覧から削除したい講師を選びます。
2. 「選択した講師を削除」を押します。

### 初期化

「講師マスターを初期化」を押すと、架空のサンプルデータへ戻ります。

## 会場テンプレート管理

公開コード内の会場情報は架空のサンプルです。実在する会場名、住所、アクセスは、画面から登録し、ブラウザ内の `localStorage` にのみ保存してください。

### 会場の追加

1. 「会場テンプレート管理」でテンプレート名、会場名、会場補足、郵便番号、住所、アクセスを入力します。
2. 「会場を追加」を押します。

### 会場の削除

1. 登録済み会場の一覧から削除したい会場を選びます。
2. 「選択した会場を削除」を押します。

### 初期化

「会場テンプレートを初期化」を押すと、架空のサンプル会場へ戻ります。

## Google Apps Script への貼り付け方法

1. Googleフォームの回答先スプレッドシートを開きます。
2. メニューから「拡張機能」→「Apps Script」を開きます。
3. 生成された「自動返信メール用 Apps Script」を貼り付けます。
4. リマインダーメールも使う場合は、別ファイルまたは同じプロジェクト内に「リマインダーメール用 Apps Script」を貼り付けます。
5. 保存後、必要なトリガーを設定します。

## トリガー設定方法

### autoReply

- 実行する関数：`autoReply`
- イベントのソース：スプレッドシートから
- イベントの種類：フォーム送信時

### sendReminder

- 実行する関数：`sendReminder`
- イベントのソース：時間主導型
- 時間ベースのトリガーのタイプ：日付ベースのタイマー
- 時刻：午前8時〜9時

`sendReminder` は、開催日の3日前から当日まで毎朝チェックし、まだリマインド未送信の申込者だけに送信します。

## 注意事項

- B列がメールアドレス、C列が名前である前提です。
- `申込返信済み`、`返信日時`、`リマインド送信済み`、`リマインド日時` の列は削除しないでください。
- テスト時は、まず自分のメールアドレスで送信確認してください。
- Google Apps Script 初回実行時は、Googleの権限承認が必要です。
- 入力値はそのままメール本文や案内文に反映されます。公開前に内容を確認してください。
- このツール自体はサーバー通信を行わず、個人情報や講座情報を外部送信しない設計です。
- GitHub リポジトリには、実在する病院名、職員名、会場名、住所、電話番号、URLを保存しないでください。
