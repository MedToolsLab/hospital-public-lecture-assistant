# 公開講座AIアシスタント Ver.1

## ツール概要

公開講座AIアシスタントは、病院広報担当者向けの静的Webツールです。
公開講座の情報を入力すると、Googleフォーム申込者へ送る以下のGoogle Apps Scriptを生成できます。

- 自動返信メール用コード `autoReply`
- 3日前リマインダー用コード `sendReminder`
- Googleフォーム送信完了メッセージ
- 自動返信メール本文プレビュー
- リマインダーメール本文プレビュー

HTML / CSS / JavaScriptのみで作成しているため、GitHub Pagesで公開できます。

制作背景や改善の流れは [PORTFOLIO.md](PORTFOLIO.md) にまとめています。

## 使い方

1. `index.html` をブラウザで開きます。
2. 講演名、開催日、講師、会場、問い合わせ先などの講座情報を入力します。
3. 「コードを生成」をクリックします。
4. 生成されたコードまたは本文プレビューの「コピー」をクリックします。
5. Google Apps Scriptに貼り付けて使用します。

## データ保存とバックアップ

- 入力内容、基本設定、講師マスター、会場テンプレートはブラウザの `localStorage` に保存されます。
- 端末変更やブラウザのキャッシュ削除に備えて、「設定をバックアップ」でバックアップを保存してください。
- 復元する場合は「バックアップを読み込む」から保存済みファイルを選択します。
- バックアップファイルの内部形式はJSONですが、通常の利用では意識する必要はありません。
- 初期化ボタンを押すと確認ダイアログが表示されます。誤操作に注意してください。

## 入力補助

- 開催日を入力すると曜日が自動表示されます。
- 日付表記は西暦と和暦を切り替えられます。
- 郵便番号はハイフンあり・なしのどちらでも入力できます。
- 住所自動補完は、外部APIへ入力内容を送信しない設計を維持するためVer.1では未使用です。
- 登録済みの会場テンプレートは「よく使う会場テンプレート」から講座情報へ反映できます。

## Google Apps Scriptへの貼り付け方法

1. 申込者一覧のGoogleスプレッドシートを開きます。
2. メニューから「拡張機能」→「Apps Script」を開きます。
3. 既存のコードを削除し、生成された `autoReply` のコードを貼り付けます。
4. リマインダーも使う場合は、同じプロジェクト内に生成された `sendReminder` のコードを続けて貼り付けます。
5. 保存します。

## トリガー設定方法

### autoReply

Googleフォーム送信時に自動返信するため、以下のトリガーを設定します。

1. Apps Script画面左側の「トリガー」を開きます。
2. 「トリガーを追加」をクリックします。
3. 実行する関数に `autoReply` を選びます。
4. イベントのソースに「スプレッドシートから」を選びます。
5. イベントの種類に「フォーム送信時」を選びます。
6. 保存します。

### sendReminder

開催日の3日前から当日まで毎朝チェックするため、以下のトリガーを設定します。

1. Apps Script画面左側の「トリガー」を開きます。
2. 「トリガーを追加」をクリックします。
3. 実行する関数に `sendReminder` を選びます。
4. イベントのソースに「時間主導型」を選びます。
5. 時間ベースのトリガータイプに「日付ベースのタイマー」を選びます。
6. 時刻に「午前9時〜10時」を選びます。
7. 保存します。

## 注意事項

- Googleフォームの回答シートは、B列がメールアドレス、C列が名前である前提です。
- `autoReply` はGoogleフォーム送信時トリガーで動作する前提です。
- `sendReminder` は時間主導型トリガーで毎朝実行する前提です。
- テストのために開催日を変更した場合、テスト後は必ず本番日に戻してください。
- `sendReminder` は「リマインド送信済み」列がない場合に自動追加します。
- 二重送信を防ぐため、「リマインド送信済み」列は削除しないでください。
- 本番運用前に、必ずテスト用フォームとテスト用メールアドレスで送信確認をしてください。
